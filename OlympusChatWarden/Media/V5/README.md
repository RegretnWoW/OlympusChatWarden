# Alpha8 transparency repair

Eight existing atlases edited with the built-in imagegen tool. Exterior alpha cleanup; native conversion resizes to power-of-two dimensions and writes uncompressed 32-bit BGRA TGA. Alpha is retained. No private signing material is included.

The requested export alpha pass removes only exposed near-black pixels in a bounded two-pixel band, smooths the resulting cutout, and bleeds RGB into fully transparent texels to prevent a black linear-sampling matte. Visible interior pixels at least five pixels inside the opaque silhouette are verified unchanged by this pass. Alpha round-trips through the native TGA without loss. Atlas crop rectangles were reviewed against the new sheets. Previous assets remain in earlier version folders; the release ZIP includes V5 only.

## Ornament

Use case: background-extraction. Edit target: Ornament.png fantasy game UI texture atlas. Perform a precise ALPHA/TRANSPARENCY REPAIR, not an artwork redesign. Remove the black exterior keyline, opaque black outline, black drop shadow, stray red/yellow matte and dark antialiased fringe OUTSIDE every bronze/gold silhouette. Those exterior pixels must become truly transparent. Keep the interior dark navy/gray panels, dark recessed metal shading, blue glows, parchment, every icon, label, bevel and original colors intact. CRITICAL: preserve the exact square canvas, every component's scale, position, layout and silhouette coordinates; the game samples this image using fixed UV rectangles. Do not enlarge, move, crop, rearrange, add or remove components. Change only the exterior cutout alpha edge, using clean narrow antialiasing without any black or colored halo on gray or pale backgrounds. Transparent pixels around components must have alpha zero, not opaque black. Return the repaired full Ornament atlas on a genuinely transparent background.
