# Alpha7 cleaned bronze artwork

Edited with the built-in imagegen tool from the V3 sources. Exterior dark edging was softened while keeping interior bronze shading, navy panels and the existing components. Native TGA assets are uncompressed 32-bit BGRA with eight alpha bits and top-left origin. PNG inspection copies are omitted from install ZIPs. Conversion only resizes to power-of-two native texture sizes and changes file format.


## Logo

Use case: precise-object-edit. Asset type: native fantasy game UI Logo illustration. Edit target: the attached Logo.png. Remove the heavy BLACK exterior strokes, black outer drop shadows and black matte fringe bordering the bronze silhouettes. Replace that exterior black edging with clean true alpha transparency and a very thin warm brown bronze edge where needed. Keep the existing artwork, muted bronze/copper colors, blue accents, parchment, interior shading, interior dark panels and all details. Absolutely preserve the square canvas, exact placement, dimensions and coordinates of EVERY individual component. No rearrangement, no redesign, no additions, no missing components, no new text. Outside each silhouette must be genuinely transparent, with clean antialiased edges that look good over medium gray. Do not erase dark interior recesses or navy cloth. Return the full cleaned Logo asset only.
