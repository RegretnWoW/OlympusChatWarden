# Olympus Warden 1.1.4-rc3

Olympus Warden connects ChronicleWarden, IntelWarden, ChatWarden, SignalWarden, ShieldWarden and RelayWarden through one Olympus-themed workspace. CommandWarden controls module choices and suite settings. Existing Olympus integration and membership/privacy requirements remain.

This candidate introduces Athena's local source-linked history, progressively enriched player dossiers, meaningful collection tiers, contextual cast counts, broader startup recovery and more stable history browsing. Read RELEASE-NOTES.md for all changes since the supplied public 1.1.3 build.

Install only the OlympusChatWarden folder. `/warden` opens the suite; `/warden chronicle check` shows recording and recovery readiness. Recording, witness/duel detail, chat capture, alerts and native shortcuts retain their own permissions. Unavailable facts stay unknown. No player/guild sync or new indefinite chat retention is enabled.

With WoW fully closed, back up complete SavedVariables before upgrading. Keep the original addon ZIP and matching backup. Existing accepted history is retained; pending recovery must be included. Do not clear history to work around a loading error. Older readers may not understand new additive record types, so roll back only in an isolated environment with the matching backup.

RC2 is prepared for final live-client smoke testing. Offline checks do not prove native API delivery, secure UI behavior, BG CPU/memory or physical disk save. RELEASE-CHECKS.md is the current short checklist. No automatic installation or public publication has been performed.
