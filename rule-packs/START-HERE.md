# Start here — renamed ChatWarden 1.0.1 packs

Open **Import These Packs**. These eight files have the current signed names.
Copy a wanted file's entire contents, then use ChatWarden > Packs > Import signed
pack > Verify pack > Install pack. Updates preserve your enabled choice and
sensitivity. You do not need to remove the old pack first.

Updating the addon does not replace saved imported packs. Import the v11 files
to update the six terminology titles. USA v6 and Body-label replacements v7 are
unchanged. Existing v11 imports already have the new titles and need no reimport.
